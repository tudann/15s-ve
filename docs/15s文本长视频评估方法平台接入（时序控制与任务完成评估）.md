# 15s文本长视频评估方法平台接入（时序控制与任务完成评估）

# 1、方法与运行环境

|**项目**|**填写内容**|
|---|---|
|方法名称与用途|**15s视频时序控制与任务完成评估**。输入已有视频及完整提示词，评估动作顺序、时间定位、持续时长、间隔、次数、并行与角色绑定，以及完整任务完成情况。输出1–5分，分数越高表示完成越好；不包含音频及整体画质评分。|
|代码与版本|部署服务器：`10.0.48.68`；目录：`/pfs/pfs-spMCeu/eval_team/Video-eval/YYC/video_long_val`。项目版本：`video-long-val 0.5.0`；当前时间线评分版本：`temporal-timeline-qwen-v0.3.3`。|
|环境与依赖|Python ≥3\.10；`jsonschema>=4.0`；ffmpeg、ffprobe。在项目根目录执行`python3 -m pip install .`安装Python包及依赖；媒体工具加入PATH，或通过`FFMPEG_BIN`、`FFPROBE_BIN`指定路径。|
|必要配置|使用`configs/qwen.local_8011.example.json`。模型为`Qwen3-VL-32B-Instruct`；示例地址为`http://127.0.0.1:8011/v1`，跨机器或容器部署时改为实际可达地址。凭据通过`LOCAL_QWEN_API_KEY`注入。保留`input_mode=frames`、`video_fps=4`、`max_images_per_call=48`、`score_mode=qwen_rubric`、`task_mode=auto`；单次模型请求超时240秒。原生批量入口串行执行，无内置并发参数；平台调度建议从1路开始。|

# 2、输入与调用

**输入： **方法接收本地媒体文件路径，平台先下载或挂载视频，再调用评估函数。

|字段|类型|必填条件及示例|
|---|---|---|
|`video_path`|string|必填，视频本地绝对路径，如`/data/video.mp4`。|
|`metadata.id`|string|建议必填，平台样本唯一标识，如`sample_001`。|
|`metadata.prompt`|string|必填，原始完整提示词，不能只传摘要。|
|`metadata.type`|string|本次按`T2V`接入；图生视频使用`I2V`。|
|`metadata.target_duration_s`|number|本次显式传`15`，单位秒。|
|`metadata.reference_image`|string|I2V必填，输入首帧图的本地绝对路径；T2V不需要。|
|`metadata.evaluation_type`|string|可选，如`时序控制与任务完成`。|

**调用方式：**使用Python函数`longval.automatic.evaluate_video`。执行目录为上述项目根目录。下面读取已有真实样例，运行结果另存到新目录；平台接入时将`request`替换为自己的样本输入，每条任务使用独立输出目录。

# 3、输出约定（完整样例：输入\-输出）

|**内容**|**填写内容**|
|---|---|
|成功或失败|`status="success"`表示流程完成；`status="error"`表示流程失败。流程完成后仍可能得到低分。|
|最终分|`score`为1–5整数，越高越好；由Qwen直接给分，取T7，不对分项平均或加权。流程失败时为`null`。|
|分项与原因|`dimension_scores`固定返回T1–T7，每项有`name`、`score`、`status`、`reason`，适用时另含证据引用。T1顺序；T2时间定位；T3持续时长；T4间隔与节奏；T5次数；T6并行与角色绑定；T7完整任务完成。`scored`显示分数，`not_applicable`显示N/A，`not_evaluated`显示N/E，`error`显示失败；后三类score为`null`，不能填0。|
|失败信息及结果文件|失败时读取`error.stage`、`error.type`、`error.message`。Python单条调用在`output_dir`保存`result.json`及该条证据，`details_dir`返回其位置；批次CSV和summary不由此函数生成。平台保存完整返回JSON，并展示最终分、分项和原因即可。|
